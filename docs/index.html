功能

选 APK → 改清单 → 增删条目 → 对齐重打包 → 重签名，输出可直接安装的新包；也支持 XAPK / APKS / split 多包容器。

清单改写

versionName / versionCode / versionCodeMajor / minSdk / targetSdk / 包名 / 应用名，属性缺失会自动补齐。

包名联动

一次改包名，四处同步：AndroidManifest 字符串池、dex 字符串表、resources.arsc 全局池、.so 等长替换。

条目增删

替换 / 新增 / 删除包内任意条目或目录前缀，重打包保留原 extra field，支持 Zip64。

重打包对齐

4 字节与 16KB 页对齐体检，签名前能看清每一段是否合规。

重签名

V1 / V2 / V3 / V4 可分别开关，内置 PKCS#12 密钥管理，产物可直接安装。

体检

包名 / 版本 / SDK / DEX / ABI / 权限统计、加固壳识别、签名者证书指纹与有效期。
