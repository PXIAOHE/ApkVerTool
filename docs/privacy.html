隐私政策

ApkVerTool · 最近更新 2026-10-12
一句话版本：ApkVerTool 是纯本地工具，不注册、不登录、不收集任何个人信息，不上传你的任何文件；只有你在设置里点「检查更新」或冷启动自动检查时，才会向公共 CDN 请求一份版本清单。

1. 我们处理哪些信息

不收集。应用没有账号体系、没有统计 SDK、没有广告 SDK、没有崩溃上报 SDK，也不会读取或上传你的通讯录、短信、位置、相册、设备标识等信息。

2. 你选择的文件

你通过系统文件选择器（SAF）交给 ApkVerTool 的 APK / XAPK / APKS 文件，只在本机内存与本地存储中被解析、修改、重打包、重签名。修改结果写到你自己指定的输出目录。文件内容不会离开设备，也不会被上传到任何服务器。

3. 联网行为

场景请求目标发送内容
检查更新（冷启动每 12 小时一次，或你在设置里手动点） cdn.jsdelivr.net（版本清单）与 api.github.com（备用来源） 仅一次普通 HTTP GET；除默认请求头（含应用版本号）外不发送任何设备或个人信息
点击「去下载 / 打开下载页」 交给系统浏览器打开公开链接 由浏览器接管，与 ApkVerTool 无关
打开「开源地址」等外链 交给系统浏览器打开 同上

4. 权限用途

权限用途
INTERNET仅用于上面第 3 节描述的版本检查与打开外链。
REQUEST_INSTALL_PACKAGES仅当你主动点击「安装」、安装你自己生成的 APK 时，交给系统安装器完成安装；应用不会静默安装任何东西。
存储读写读取你选择的 APK、把修改结果写到你指定的输出目录；不扫描你的其它文件。

5. 数据存储与删除

应用只在本机保存你自己的设置（主题、输出目录、签名密钥与密码、更新检查时间戳）。卸载应用即全部删除，我们不保留任何副本。

6. 第三方

除上述公共 CDN / GitHub 的版本清单请求外，应用不集成任何第三方数据收集服务。应用使用的开源库（AndroidX / Jetpack Compose、Material 3、Miuix、AOSP apksig 等）均为本地代码库，不参与数据收集。

7. 儿童

本应用面向具备 Android 应用包处理知识的开发者与进阶用户，不面向儿童，也不会有意收集儿童信息。

8. 变更与联系方式

政策如有变更会在本页与仓库更新说明中体现。任何疑问请到 GitHub Issues 反馈。
