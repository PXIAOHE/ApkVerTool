条目增删

FAQ

常见问题

真的免费吗？

免费且开源（Apache-2.0）。没有广告、没有统计 SDK、没有账号体系，也没有隐藏收费。

会把我的文件上传吗？

不会。你选中的 APK 只在本机被解析、修改、重打包、重签名，结果写到你指定的输出目录；联网只用在你主动点「检查更新」时拉一份版本清单。

需要 root 吗？

改写、体检、重签名都不需要 root。只有「改完之后直接安装到系统里」这一步，遇到未签名或签名不一致的包时，系统才会要求 root + 核心破解。

支持哪些包类型？

.apk 单包与多选批量，以及 .xapk / .apks / split 压缩包；容器内每个子包会分别处理并回填元数据。

系统要求与体积？

{{MIN_ANDROID}} 及以上，当前版本 v{{NAME}} 约 {{SIZE_HUMAN}}，单个 APK 安装即用。

改完的包能直接装吗？

默认会重签名，产物可直接安装；如果关掉「重新签名」，输出是 MT 式的不重签包，仅供二次处理，不能直接安装。
